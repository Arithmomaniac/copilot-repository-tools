# Snapshot Test Fixtures

Real session data used for integration and snapshot testing. These files are **not committed** to the repository (see `.gitignore`).

## Setup

Both `fixtures/` and `baselines/` are stored in a **shared location** outside any single worktree so that all worktrees and the main repo can share the same data:

```
C:\_SRC\copilot-repository-tools.snapshots\
├── fixtures\    # Real session files
└── baselines\   # Golden-file outputs
```

Each repo checkout or worktree should have `tests/snapshots/fixtures` and `tests/snapshots/baselines` as **NTFS junctions** pointing to the shared location:

```powershell
# From the repo/worktree root:
cmd /c mklink /J tests\snapshots\fixtures  C:\_SRC\copilot-repository-tools.snapshots\fixtures
cmd /c mklink /J tests\snapshots\baselines C:\_SRC\copilot-repository-tools.snapshots\baselines
```

Junctions don't require admin rights (unlike symlinks) and are transparent to Python's `pathlib`.

## Baselines

The `baselines/` directory holds golden-file outputs generated by running the scanner/exporter against fixtures. These are used by snapshot tests to detect regressions.

To regenerate all baselines after intentional changes:

```bash
uv run pytest tests/test_snapshot.py --regen-all -v
```
